# Calculadora de Média

Projeto simples desenvolvido com **HTML, CSS e JavaScript** para calcular a média de duas notas.

## Como funciona

Informe a primeira e a segunda nota e clique em **Calcular média**. O projeto calcula a média aritmética e apresenta uma classificação:

- **Aprovado:** média igual ou superior a 7.
- **Recuperação:** média igual ou superior a 5 e inferior a 7.
- **Reprovado:** média inferior a 5.

Depois do resultado, clique em **Calcular novamente** para limpar os campos e fazer outro cálculo.

## Como executar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: estilos e apresentação visual.
- `treinando.js`: cálculo da média e exibição do resultado.
- `background-img.png`: imagem de fundo usada na página.
