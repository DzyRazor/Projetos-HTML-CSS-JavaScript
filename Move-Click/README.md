# Move-Click

Projeto interativo feito com **HTML, CSS e JavaScript**. O botão **Iniciar** se move para uma posição aleatória quando o cursor passa sobre ele. Se conseguir clicar, a página mostra uma mensagem de sucesso. O botão de informações também exibe ou oculta as instruções do projeto.

## Como executar

É necessário ter o Node.js e o npm instalados.

1. Abra um terminal nesta pasta (`Move-Click`).
2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor local:

   ```bash
   npm start
   ```
